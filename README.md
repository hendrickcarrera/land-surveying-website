# Quadrant Surveying Services (Imus)

A single-page marketing website for Quadrant Surveying Services, a land surveying business in Imus, Cavite. It presents the company's services and fieldwork and turns visitors into quote requests.

**Live site:** https://quadrant-surveying-services.vercel.app/

## Features
- Hero section with a call to action to request a quote
- Field work gallery with a lightbox
- "How it works" four-step process
- Full services list grouped by category
- Welcome modal with smooth animations
- Responsive, mobile-first layout

## Tech stack
- React 19 + TypeScript
- Vite
- Tailwind CSS v4 (design tokens via `@theme`)
- React Router
- React Hook Form + Zod
- Framer Motion
- lucide-react icons
- Deployed on Vercel
